# 设备通信排查清单

按层记录同一时间段的计数：

1. FPGA/设备生成包数和序号。
2. 物理链路和网卡错误。
3. 驱动与 IRQ。
4. 内核 UDP/TCP 统计。
5. socket 缓冲区和应用 recv 数量。
6. 协议缺失、重复、乱序、CRC 错误。
7. 业务队列、处理数和展示数。

```bash
ip -s link
ethtool -S eth0
cat /proc/interrupts
grep -A1 '^Udp:' /proc/net/snmp
ss -u -a -n -m
tcpdump -i INTERFACE -nn -tt
```

只有相邻两层计数不一致，才能把问题边界缩到这两层之间。
