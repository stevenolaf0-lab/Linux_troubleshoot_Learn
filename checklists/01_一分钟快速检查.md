# 一分钟快速检查

## 先记录

- 故障精确时间、持续时间、是否自动恢复。
- 输入数据、设备参数、软件版本和启动参数。
- PID、目标机架构、剩余磁盘和内存。

## 命令

```bash
date --iso-8601=ns
uname -a
uptime
free -h
df -h
ps -p PID -o pid,ppid,lstart,etime,stat,pcpu,pmem,rss,vsz,cmd
ps -L -p PID -o tid,comm,stat,psr,pcpu,wchan:24
grep -E 'VmRSS|VmSize|Threads' /proc/PID/status
ss -a -n -p
dmesg -T | tail -100
```

## 快速分流

- 进程消失：崩溃、OOM、主动退出，查 core 和 journal。
- 单线程满核：perf。
- CPU 低但不响应：strace、全线程栈。
- RSS 增长：队列/缓存指标、ASan、Heaptrack。
- GUI 卡：GUI 心跳、GUI 线程栈、绘制频率。
- 数据缺失：设备序号、抓包、内核和应用计数。
