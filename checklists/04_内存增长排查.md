# 内存增长排查清单

1. 观察 VmRSS，而不是只看 VmSize。
2. 同时记录队列、缓存、历史数据、线程和 FD 数量。
3. 判断增长是持续、阶梯、周期还是达到平台。
4. 检查 OOM 和 cgroup 限制。
5. 小场景用 ASan/Valgrind，长场景用 Heaptrack。
6. 区分 definitely lost、still reachable 和峰值内存。

```bash
pidstat -r -p PID 1
cat /proc/PID/smaps_rollup
pmap -x PID | tail -1
dmesg -T | grep -i -E 'oom|killed process'
```
