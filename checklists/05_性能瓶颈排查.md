# 性能瓶颈排查清单

1. 固定输入、线程数、持续时间和构建类型。
2. 先确认瓶颈资源：CPU、内存、I/O、网络或设备。
3. 找到具体线程。
4. 使用 perf 找到具体函数和调用链。
5. 检查复制、分配、锁等待和刷新频率。
6. 记录吞吐、P50/P95/P99 延迟和正确性。
7. 相同场景对比修复前后。

```bash
pidstat -p PID -t -r -d -w 1
perf stat -d -p PID -- sleep 20
perf record -F 99 -g -p PID -- sleep 20
perf report
```

QEMU 性能不能代表真实 ARM64。
