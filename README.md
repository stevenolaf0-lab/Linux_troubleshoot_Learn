# Linux 设备控制软件排障学习实验室

本项目用于系统学习 Linux 下设备控制软件的开发、运行监控和故障排查。

目标场景包括示波器、频谱分析仪、无线通信设备和其他包含数据采集、算法处理、缓存队列与界面绘制的软件。

## 学习目标

完成本项目后，应当能够定位和分析：

- 程序崩溃与段错误；
- 内存越界、释放后使用和内存泄漏；
- 线程死锁、条件变量等待和系统调用阻塞；
- CPU 使用率过高与算法热点；
- 队列积压与端到端延迟；
- Qt 界面卡顿与刷新性能问题；
- 动态库、ELF、符号和 ABI 问题；
- 网络通信、UDP 丢包和模拟 FPGA 数据链路问题；
- 软件瓶颈与硬件瓶颈；
- systemd 服务和现场日志采集。

## 统一排障方法

每次实验都遵循同一个闭环：

1. 固定输入数据、配置、软件版本和运行时间。
2. 准确记录故障发生时间和外部现象。
3. 同时采集系统指标与程序内部指标。
4. 根据证据提出假设，而不是直接猜测原因。
5. 将问题定位到进程、线程、函数、源码行或外部资源。
6. 修复后使用相同场景重新测试。
7. 使用 Git 保存实验过程和修复结果。

## 实验环境

当前主要环境：

- Ubuntu 24.04 WSL；
- x86-64 处理器架构；
- GCC 和 CMake；
- Git 与 GitHub。


后续还会学习：

- GDB、core dump 和 Valgrind；

- ARM64 交叉编译；
- x86-64 与 ARM64 环境差异；
- Qt 界面线程和绘图性能分析。
